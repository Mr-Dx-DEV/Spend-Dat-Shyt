## 📦 Installation Guide

The installation process is straightforward. Please follow the steps below carefully:

### 1. Import the Database

* Upload the provided **XP SQL file** to your database.
* ⚠️ **Important:** The script will not function correctly without this step.

---

### 2. Install Inventory Items

* Navigate to the `install_me` folder.
* Upload:

  * All **items** to your inventory system.
  * All **images** to your inventory image directory.

---

### 3. Configure the Script

* Open `Config.lua`.

* Adjust the following as needed:

  * Framework settings
  * Prices
  * NPC coordinates

* ⚠️ This step is **crucial** for proper functionality.

---

### 4. Set Up Webhooks (Optional but Recommended)

* Open:

  ```
  server/webhooks.lua
  ```

* Add your Discord webhooks.

* 💡 While optional, we **strongly recommend** enabling logs for better tracking and debugging.

---

### 5. You're Done! 🎉

Your script should now be fully installed and ready to use.
