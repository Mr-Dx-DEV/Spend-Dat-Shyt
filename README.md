## 📖 About

Spend Dat Shyt is a custom-built FiveM Roleplay server focused on performance, stability, and immersive gameplay.

The server includes a balanced economy, custom jobs, advanced criminal activities, optimized resources, and high-quality UI/UX designed for long-term community growth.

## ⚙ Requirements

* Latest FiveM Artifact
* MariaDB / MySQL
* Node.js
* txAdmin
* Windows or Linux VPS

---

## 🚀 Installation

1. Clone this repository.
2. Import the SQL database.
3. Configure `server.cfg`.
4. Add your CFX License Key.
5. Start the server using txAdmin.
