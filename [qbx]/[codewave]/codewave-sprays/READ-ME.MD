1. Ensure you head to the config & adjust all the values you need to work with your server.

2.  Head to "INSTALL-ME" this is the icons for the script, Includes all pngs (if you do not like them, make your own if you wish!)

3. Ensure to set your framework in the config (IT IS CASE SENSITIVE SO BE SURE TO USE ESX OR QBCore)

4. If you choose to use the client phone you MUST set up the prices seperately in that config, their is a read-me attached in their for that.
