# 💋 Sugar Hustle – Installation

This folder contains installation and reference docs for **Sugar Hustle**. For a full list of features and customer-facing overview, see the main **[README.md](../README.md)** in the resource root.

## Quick start

1. Place the `sugar_hustle` folder in your resources directory.
2. Add required items to your framework (see [ITEMS_REFERENCE.md](ITEMS_REFERENCE.md)).
3. Configure `config.lua`.
4. Add `ensure sugar_hustle` to your `server.cfg`.
5. Restart the server.

## Key features (summary)

- Multi-framework (QBCore, QBOX, ESX), multiple partners, relationship levels, personalities.
- Encounters (cash, gifts, drama, police), dates, meet requests, optional AI messages.
- Robbery and **blackmail** (pay in time or face police/relationship loss).
- Pawn shop (luxury goods) and optional Plug (drug orders).

See **[../README.md](../README.md)** for the full feature list and player-facing guide.
