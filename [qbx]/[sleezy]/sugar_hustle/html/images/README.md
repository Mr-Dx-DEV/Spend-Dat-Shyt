## 🎨 Image Specifications

### **Size & Format**
- **Recommended Size**: 500x500px (or 1:1 ratio)
- **Format**: JPG or PNG
- **File Size**: Keep under 200KB for performance

### **Style Guidelines**
- **Professional portraits** (stock photo style)
- **Clear face visibility**
- **Neutral or luxury backgrounds**
- **Good lighting**
- **Matching the personality** (e.g., Generous = sophisticated, Flirty = stylish)

## 📝 Quick Setup Instructions

1. **Download** 10 portrait images from free stock sites
2. **Rename** them to match the profile names:
   - `vanessa.jpg`, `isabella.jpg`, etc.
3. **Resize** to 500x500px (square) using an image editor
4. **Optimize** file size (under 200KB each)
5. **Place** all images in this folder
6. **Test** in-game to ensure they load correctly
