# FS-DOJ - Department of Justice MDT System

A comprehensive Department of Justice roleplay system for FiveM servers featuring a fully-functional Mobile Data Terminal (MDT), case management, court proceedings, warrant system, and law enforcement tools.

## Features

- **Multi-Framework Support** - Auto-detects and works with ESX, QBCore, and QBox frameworks
- **Mobile Data Terminal (MDT)** - Complete tablet-based interface with dashboard statistics
- **Citizens Database** - Comprehensive citizen records with automatic player sync, notes, and flags
- **Vehicle Registry** - Complete vehicle database with plate lookups and status management
- **Case Management** - Create and manage criminal, civil, traffic, and administrative cases
- **Reports System** - Create detailed incident reports with narratives and case linking
- **Court System** - Schedule hearings, assign judges, enter verdicts and sentences
- **Warrant Management** - Issue arrest, search, bench, and seizure warrants
- **License Management** - Issue, suspend, revoke, and restore citizen licenses
- **Business Registry** - Company database with employee and financial tracking
- **Financial System** - DOJ society account with deposits, withdrawals, and transaction history
- **Inspections Logging** - Record traffic stops, searches, and property inspections
- **Announcements System** - Post department-wide announcements
- **Printer System** - Print reports and documents at configured locations
- **Court TV Display** - Synchronized displays for court schedules and announcements
- **Gavel & Microphone System** - Interactive courtroom tools with 3D spatial audio
- **Metal Detector System** - Automatic weapon detection at courthouse entrances
- **Permission System** - Hierarchical 8-grade permission system

## Requirements

- **Framework:** ESX, QBCore, or QBox
- **Database:** oxmysql
- **Library:** ox_lib
- **Inventory:** ox_inventory (recommended) or qb-inventory
